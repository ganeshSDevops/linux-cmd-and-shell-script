1) Find ERROR lines from a log
grep "ERROR" app.log

2) Case-insensitive search
grep -i error hotstat-app-logp

3) Show line numbers
grep -n "ERROR" app.log

4) Count matches
grep -c INFO hotstat-app-log

5) Invert match (lines NOT containing word)
grep -v INFO hotstat-app-log

6) Search recursively in directory
grep -r "password" /etc/

7) Match whole word only
grep -w "root" /etc/passwd

SED:
1) Replace word in file
sed 's/localhost/127.0.0.1/g' file.txt
but this only replace in terminal output not in actual file

2) Replace word in file inplace 
sed -i 's/localhost/127.0.0.1/g' file.txt  // -i used replace in place 
// g is used replace all word in file 
// if you dont know use "g" then it will replace only 1st word in line 
// if there is second occurnace in file then it will not replace 

3)  Replace only in line 5
sed '5s/old/new/' file.txt

4) Delete lines matching pattern
sed '/DEBUG/d' app.log

5) Insert line before pattern
sed '/ERROR/i This is error line' app.log

6) Append line after pattern
sed '/ERROR/a Check immediately' app.log

7) Edit file in-place
sed -i 's/dev/prod/g' config.txt

8) Print only matching lines (like grep)
sed -n '/ERROR/p' app.log

🔵 AWK – Column processing & reporting
Assume emp.txt:
101 Ram IT 50000
102 Sam HR 40000
103 Raj IT 60000

1) Print first column
awk '{print $1}' emp.txt

2) Print 1st and 4th column
awk '{print $1, $4}' emp.txt

3) Sum of salaries (4th column)
awk '{sum+=$4} END {print sum}' emp.txt

4) Print rows where department is IT
awk '$3=="IT"' emp.txt

5) Print rows where salary > 45000
awk '$4>45000' emp.txt

6) Count number of lines
awk 'END{print NR}' emp.txt

7) Use custom delimiter (CSV)
awk -F',' '{print $1}' file.csv

8) Add header and formatted output
awk 'BEGIN{print "ID Salary"} {print $1, $4}' emp.txt


🟣 FIND – File hunting in servers
1) Find file by name
find / -name "config.yaml"

2) Case-insensitive
find / -iname "config.yaml"

3) Find files modified in last 2 days
find /var/log -mtime -2

4) Find files larger than 100MB
find / -size +100M

5) Find and delete files older than 7 days
find /tmp -mtime +7 -exec rm -f {} \;

6) Find empty files
find / -type f -empty

7) Find directories only
find / -type d -name "logs"

8) Find and change permission
find /data -type f -name "*.sh" -exec chmod +x {} \;

🔥 Mixed Real Interview Scenarios (Very Important)
▶ Find ERROR count from all logs
grep -r "ERROR" /var/log | wc -l

▶ Replace IP in all config files
find /app -name "*.conf" -exec sed -i 's/10.0.0.1/10.0.0.2/g' {} \;

▶ Print usernames from /etc/passwd
awk -F':' '{print $1}' /etc/passwd

▶ Find top 5 largest files
find / -type f -exec du -h {} + | sort -rh | head -5

▶ Remove blank lines
sed '/^$/d' file.txt

▶ Print lines between two patterns
sed -n '/START/,/END/p' file.txt
